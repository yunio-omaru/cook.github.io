ヤンニョムタルタルチキン
鳥,ヤンニョム
主食
材料
  • 鶏むね肉：1枚
  • A 酒、醤油、マヨネーズ：各小さじ1
  • A 片栗粉：大さじ2
  • -タルタル-
  • ゆで卵：2個
  • B マヨネーズ：大さじ2〜3
  • B 塩こしょう：適量
  • -たれ-
  • C ケチャップ：大さじ2
  • C コチュジャン：大さじ1
  • C 醤油、みりん：各小さじ2
  • C 砂糖：小さじ1
  • C にんにくすりおろし：小さじ1/2
作り方
  1. 1. 鶏むね肉をそぎ切りし、Aを揉み込む。
  2. 2. ゆで卵を崩し、Bと混ぜてタルタルを作る。
  3. 3. フライパンに油を熱し、鶏肉を焼く。
  4. 4. 火が通ったらCを加えて絡める。
  5. 5. 器に盛り、タルタルソースをかける。
